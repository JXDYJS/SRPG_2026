# 思政报告

## 一、课程与个人发展计划的关系

### 1.1 个人职业规划与项目定位

我的职业目标是成为一名具备底层技术能力的**游戏引擎与工具链工程师**。在当前的游戏行业，大量的独立开发者和中小型团队受困于"重复造轮子"的困境——每个新项目都需要从零搭建战斗系统、AI框架、资源管理管线。我希望通过本课程的学习与实践，掌握**大型游戏系统的架构设计能力**，未来能开发一套通用的SRPG（战棋角色扮演）游戏开发框架，为中小团队降低此类游戏的研发门槛。

本课题《基于大语言模型辅助的3D体素战棋游戏架构设计与实现》正是服务于这一职业目标的**核心实践项目**。该项目覆盖了游戏引擎开发的多个关键技术栈：

- **寻路与空间算法**（3D A* 寻路、Morton 编码空间索引）——对应"引擎底层算法"能力
- **异步状态机与时序控制**（UniTask 替代 Coroutine）——对应"引擎运行时框架"能力
- **Command 模式与状态回滚**（UndoSystem + ITrackable 接口）——对应"输入解耦与重放"能力
- **数据驱动架构**（ScriptableObject + Addressables）——对应"工具链与资源管线"能力
- **AI 与决策系统**（任务竞标 + 威胁图 + 多因素效用评估）——对应"游戏AI"能力

该项目在我个人发展规划中处于**承上启下**的关键位置。在此之前，我已完成 C++ 底层编程、数据结构、计算机图形学基础（包括自定义 Shader 编写和 Compute Shader 实现 AutoExposure）的学习。通过本项目，我首次将这些理论知识系统地整合到一个完整的游戏产品中。在项目完成之后，我将进一步研究：
1. ECS（Entity Component System）架构，探索将当前的 MonoBehaviour 架构迁移到更高效的数据导向架构
2. 网络同步机制，为游戏添加多人对战功能
3. 自动化测试框架，建立可持续验证的工程质量体系

## 二、个人发展计划与社会及国家发展的关系

### 2.1 与大语言模型辅助开发的关联

本项目最大的特色在于将**大语言模型（LLM）深度嵌入游戏研发管线**。项目的多个核心算法模块由 AI 辅助生成或优化，包括但不限于：

- **3D A* 寻路启发式函数优化**：AI 协助在启发函数 $f(n) = g(n) + h(n)$ 中引入垂直距离权重
- **UI 时间轴头像重叠算法**：双向扫荡（Two-Way Sweeping）算法由 AI 辅助设计并验证
- **Morton 编码性能优化**：AI 协助将线性搜索替换为二叉堆 + Z-order 空间索引
- **代码脚手架批量生成**：Command 类定义、Buff 接口基类、Addressables 加载封装等样板代码由 AI 生成初稿

这种"AI 辅助研发"工作流的成功实践，与国家当前大力倡导的**"新质生产力"**理念高度契合。新质生产力的核心是以科技创新驱动产业升级，而 AI 辅助软件开发正是科技赋能传统生产力的典型场景。通过在项目中系统性地实践提示词工程（Prompt Engineering），我亲身体验到了 AI 如何将开发者从繁琐的样板代码中解放出来，使其能将更多精力投入到系统架构设计和创意迭代上。

### 2.2 与自主可控技术栈的关系

本项目采用的 Unity 引擎虽然源自海外，但在技术选型上始终坚持**自主可控的原则**：

- **核心算法自主实现**：3D A* 寻路、AI 决策系统、伤害计算管线等核心逻辑均为自研代码，不依赖第三方付费插件
- **渲染管线自主拓展**：基于 URP 实现了自定义 ScriptableRendererFeature（AutoExposure），而非使用商业后处理插件
- **代码自主维护**：建立了完整的命名空间规范（Core.* / GamePlay.* / UI.*），采用 Git + GitHub PR 流程，确保代码资产的长期可维护性

这种"引擎工具 + 自研核心"的技术路线，体现了在当前国际环境下中国游戏开发者**立足自主、善用工具**的技术务实态度。通过学习 Unity 引擎的底层机制（渲染管线、资源管理、物理系统），并在其上进行自主创新（如将 Morton 编码引入游戏网格系统），我深刻理解了"引进吸收再创新"的技术发展路径。

### 2.3 小结

本项目不仅是技术能力的锻炼，更是一次对"科技向善"理念的实践。游戏作为一种文化载体，承载着传播价值观念、丰富精神生活的社会功能。通过开发一款强调策略思考而非暴力刺激的战棋游戏，我希望将来能打造出有益于年轻人思维训练、具有中国文化特色的游戏产品。技术上，AI 辅助开发工作流的探索也为行业降低研发成本、提升创新效率提供了参考样本，符合国家推动数字经济发展的宏观方向。
