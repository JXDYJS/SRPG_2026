## 2. 核心算法开发阶段

### 2.1 3D A* 寻路算法

```
帮我实现一个基于 Unity C# 的 3D A* 寻路算法，要求：
- 支持 XYZ 三维网格（Y 轴为高度）
- 支持不同 BlockType 的地形通行性（Air=可通过, Solid=不可通过, Slab=半砖可通过）
- 在启发函数 h(n) 中引入垂直距离权重，使单位优先选择攀爬代价更小的路径
- G 值的计算需考虑 JumpHeight 和 FallHeight 限制
- 请使用曼哈顿距离的变体作为启发式函数
```

### 2.2 Morton 编码空间索引

```
我目前使用 Dictionary<Vector3Int, BlockType> 存储网格数据，每帧需要频繁进行坐标查找。
请帮我设计一个使用 Z-order Morton 编码将 3D 坐标编码为单个 uint64 的方案，
让我可以用 flat array 替代 Dictionary，实现 O(1) 查找并提升缓存命中率。

需要：编码函数 (x,y,z) -> uint64，解码函数 uint64 -> (x,y,z)，以及边界处理。
```

### 2.3 UI 时间轴头像重叠算法

```
我的回合时间轴 UI 有多个单位头像按 AV（行动值）从左到右排列，
当两个单位的 AV 值接近时头像会重叠。请帮我设计一个"双向扫荡"算法：
- 从左向右扫描，检测重叠并向右推
- 从右向左扫描，检测重叠并向左推
- 两个方向取最小偏移量，保证头像位置稳定
```

### 2.4 抛物线弹道判定

```
帮我实现一个抛物线弹道的多点采样 + 光线检测算法：
- 根据起点和终点计算抛物线轨迹
- 沿轨迹等距采样 N 个点
- 对每段进行 Raycast 检测
- 如果碰撞到 Solid 方块且非目标单位，判定为"拦截"
- 返回弹道是否有效
```

## 3. 代码生成与重构阶段

### 3.1 样板代码生成

```
请帮我生成以下代码的骨架：
1. 一个名为 BuffVampire 的 Buff 类，继承自 BuffBase，效果是每次造成伤害时回复伤害量 X% 的 HP
2. 一个名为 SkillExecutor 的静态类，负责技能范围验证、目标筛选和伤害计算
3. 一个 UIPanel 基类，包含 Open/Close/Focus/Blur 生命周期方法

请使用 Unity C# 编写，遵循项目的 Allman 大括号风格。
```

### 3.2 命名空间重构

```
当前项目的命名空间与文件夹结构不一致，例如 GamePlay/Units/ 文件夹下的类使用了 GamePlay.Unit 命名空间（缺少 s）。
请帮我规划一个系统性的命名空间修正方案，要求在批量修改 using 语句后，项目能零错误编译通过。
```

### 3.3 性能优化

```
AStar 的 GetReachableTiles 方法中使用 LINQ OrderBy 对 openSet 排序，在大地图上造成明显性能瓶颈。
请帮我将排序机制替换为二叉小顶堆（MinHeap），并提供 C# 实现代码。
```

## 4. AI 系统开发阶段

### 4.1 AI 决策框架设计

```
帮我设计一个战棋游戏的 AI 决策系统，要求：
1. 使用 Task 模式：AI 为当前角色生成候选任务池（Attack、Skill、Move、Support、Defend、Wait）
2. 使用 Utility 函数评估每个任务的优先级，考虑因素：伤害期望、HP 压力、距离、技能冷却、职业权重
3. 支持 Config 配置文件调整各因素权重
4. 对于无攻击目标的角色，自动向最近敌人方向前压
```

### 4.2 AI 性能优化

```
AI 系统中 AIDirector 需要为每个候选任务重复调用 AStar.GetReachableTiles，导致大量重复计算。
请帮我设计一个 AITaskContext 缓存机制，在 AI 回合开始时预计算可达地块并缓存，供所有 Task 共用。
```
