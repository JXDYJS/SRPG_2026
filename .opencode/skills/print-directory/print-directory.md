# 打印目录结构技能

**技能名称:** print-directory  
**别名:** pd, dir, ls  
**类型:** 文件系统工具  
**权限:** 只读

## 描述
这个技能用于打印当前工作目录或指定路径的目录结构。它提供了文件系统的可视化表示，包括文件大小、修改日期和权限信息。

## 语法
```bash
# 基本用法
/print-directory [路径] [选项]

# 别名
/pd [路径] [选项]
```

## 参数
- `路径` (可选): 要列出的目录路径。默认为当前工作目录。

## 选项
- `-d, --depth <数字>`: 显示的最大深度（默认: 3）
- `-s, --size`: 显示文件大小（人类可读格式）
- `-t, --tree`: 以树状结构显示
- `-a, --all`: 显示隐藏文件（以`.`开头的文件）
- `-f, --filter <扩展名>`: 按文件扩展名过滤（例如: `.cs`, `.md`）
- `-h, --help`: 显示帮助信息
- `-l, --long`: 详细格式（类似`ls -la`）
- `-r, --reverse`: 反向排序
- `-S, --sort-size`: 按文件大小排序
- `-t, --sort-time`: 按修改时间排序

## 示例
```bash
# 打印当前目录
/pd

# 打印指定目录的树状结构
/pd /path/to/dir -t -d 2

# 显示文件大小和隐藏文件
/pd -s -a

# 过滤显示C#文件
/pd -f .cs

# 详细格式，按时间排序
/pd -l -t
```

## 实现规则

### 1. 路径解析
- 如果未提供路径，使用当前工作目录
- 解析相对路径和绝对路径
- 检查路径是否存在且可访问

### 2. 目录遍历
- 使用递归或迭代方法遍历目录
- 尊重最大深度限制
- 处理符号链接（避免循环）

### 3. 格式化输出
- 使用一致的缩进和前缀
- 为目录和文件使用不同的图标/符号
- 格式化文件大小（B, KB, MB, GB）
- 格式化日期（YYYY-MM-DD HH:MM）

### 4. 错误处理
- 路径不存在: `错误: 目录不存在: /path`
- 权限不足: `错误: 无法访问目录: /path`
- 不是目录: `错误: 不是目录: /path`

### 5. 性能考虑
- 对于大型目录，限制输出行数
- 提供进度指示（如果可能）
- 使用异步操作避免阻塞

## 平台支持
- **Windows**: 使用`dir`命令或PowerShell
- **Unix/Linux**: 使用`ls`命令
- **macOS**: 使用`ls`命令

## 集成
- 可与文件搜索技能结合使用
- 支持管道输出到其他命令
- 可输出为JSON格式（如果添加`-j`选项）

## 测试用例

## 注意事项
- 这是一个只读操作，不会修改文件系统
- 大型目录可能需要较长时间处理
- 符号链接可能指向不存在的位置
- 权限问题可能限制访问某些目录
